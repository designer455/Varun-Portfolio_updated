## 2. NAVIGATION TAXONOMY & ANCHORS

### Desktop Floating Navigation Capsule
- **Brand Monogram:** `VC // 2026` (Magnetic anchor to top)
- **Primary Section Links:**
  - `[WORK]` $\rightarrow$ `#portfolio` (Jumps to Work Vault & Category Suite)
  - `[EXPERIENCE]` $\rightarrow$ `#experience` (Jumps to Career Timeline & Capabilities)
  - `[AI LAB]` $\rightarrow$ `#ailab` (Jumps to Creative AI & MCP Architecture)
  - `[CREDENTIALS]` $\rightarrow$ `#credentials` (Jumps to Certifications & Live Sites)
  - `[CONTACT]` $\rightarrow$ `#contact` (Jumps to Conversion Terminal)
- **Action CTA Pill:** `LET'S TALK ↗` (Triggers contact drawer / WhatsApp)

### Mobile Navigation Drawer
- On viewports $<768\text{px}$, the capsule compacts into a brand monogram and a minimal menu toggle button (`Menu / Close`).
- Tapping triggers a full-screen obsidian glass drawer with oversized typography, quick contact buttons, and active status indicators.

## 4. THE SIGNATURE "AI LAB & WORKFLOW" ARCHITECTURE

To establish Varun's positioning as an **AI-Powered Creative Technologist**, the AI Lab is designed around an interactive node-graph workflow rather than a static list of logos:

```
[STAGE 1: CREATIVE INTENT]
Tools: Adobe Photoshop, Illustrator, CorelDRAW, Canva
Output: Vector identities, high-res art assets, spatial wireframes

           │
           ▼
[STAGE 2: GENERATIVE AUGMENTATION]
Tools: GPT-4o, Gemini Pro, Claude Code, Codex, Antigravity
Output: Automated layout variations, programmatic copy, visual iterations

           │
           ▼
[STAGE 3: ARCHITECTURE & MCP INTEGRATION]
Tools: Custom MCP Servers, Python automated scripts, REST APIs
Output: Automated asset pipelines, frame extraction, intelligent telemetry

           │
           ▼
[STAGE 4: PRODUCTION BUILD & SHIP]
Tools: Next.js 16, React 19, TypeScript, Tailwind v4, GitHub, Vercel
Output: High-performance, zero-error, globally deployed digital products
```

Visitors can click on any stage in the workflow to inspect live code snippets, prompt architectures, or tool descriptions.
